# Third-party code

`ml-sharp/` is Apple's SHARP (arXiv 2512.10685), not included here. Restore with:

    git clone https://github.com/apple/ml-sharp.git && git -C ml-sharp checkout aed6527499ef91cba3b54c18d49a870f25947190

Datasets (LLFF, Mip-NeRF 360) and `results*/` outputs were removed to save space; regenerate them with the scripts in `nvs/`. Numbers are in PROGRESS.md.
